# ATM Simulator

A simple Python-based ATM simulation program that performs basic banking operations.

## Features

* 4-digit PIN verification
* Check account balance
* Deposit money
* Withdraw money
* Check for insufficient balance
* Continue using the ATM until the user chooses to exit

## ATM Menu

The program provides the following options:

1. Check the balance
2. Deposit
3. Withdraw
4. Exit

## How It Works

1. The user enters a 4-digit PIN.
2. If the PIN is correct, the ATM menu is displayed.
3. The user can check their balance, deposit money, or withdraw money.
4. During withdrawal, the program checks whether sufficient balance is available.
5. The balance is updated after a successful deposit or withdrawal.
6. The user can continue using the ATM or exit.

# ATM Workflow

A simple Python-based ATM simulation that demonstrates the basic operations performed through an ATM.

## Features

* PIN verification
* Check account balance
* Deposit money
* Withdraw money
* Exit the ATM
* Basic input validation

## Technology Used

* Python

## How It Works

1. The user enters their PIN.
2. After successful verification, the ATM menu is displayed.
3. The user can choose an operation:

   * Check Balance
   * Deposit Money
   * Withdraw Money
   * Exit
4. The balance is updated after deposits or withdrawals.

## Example

```text
Enter your PIN: ****

1. Check Balance
2. Deposit
3. Withdraw
4. Exit

Enter your choice: 3

Enter amount to withdraw: 500

Withdrawal successful!
Remaining balance: ₹4500
```
